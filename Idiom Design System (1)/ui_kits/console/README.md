# Console kit

The product shell, assembled from nothing but system components: `.app` grid (nav | page), `.topbar`, `ObjectHeader`, `Tabs`, and a `.split` whose dominant column holds the objective collection and whose subordinate column holds the residual panel and the work queues.

- `ConsoleScreen.jsx` — shell, object header, tabs, and the Why drawer
- `ConsoleNav.jsx` — brand slot, the nine areas in three groups, one active item
- `ConsoleCollection.jsx` — assessment cycle scope, four factual counts, determination trend, objective table, empty state
- `ConsoleAside.jsx` — `ResidualPanel` for the consumed package, `WorkRow` queue, upstream changes

What the screen is careful about: the four counts add up to the obligation and none of them is a percentage; the objective identifier is mono metadata while the statement is the readable column; Satisfied objectives are not in the table at all, because the table is what still needs a determination.

Budgets on this screen: **3 accent uses** (active nav item, active tab, primary button) and **4 of 5 hairlines** (nav edge, tab rule, table header rule, control borders). The fifth is left unspent. The drawer spends the one permitted overlay shadow.
